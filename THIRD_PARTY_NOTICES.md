# Third-Party Notices

Nightwalker is an unofficial Story Mode modification. It does not grant rights to third-party software or game content.

## Red Dead Redemption 2

Nightwalker references content already present in the user's legitimate RDR2 installation at runtime, including `cs_vampire` and selected game-authored effects and behaviors. The repository and release package do not include extracted Rockstar models, textures, animations, audio, maps, archives, executables, or other proprietary RDR2 assets.

Red Dead Redemption 2, Rockstar Games, and related names/assets belong to their respective rights holders. Nightwalker is not endorsed by or affiliated with Rockstar Games or Take-Two Interactive.

## Script Hook RDR2

Nightwalker requires a compatible Script Hook RDR2 runtime/ASI loader to run and the Script Hook RDR2 developer SDK to build from source. These files are not redistributed by Nightwalker. Users and developers obtain compatible copies separately and follow the terms that apply to them.

Local SDK headers and libraries are excluded from source control and from the release package. The repository contains setup instructions only.

## Inspiration boundary

Nightwalker may study the high-level feel of modern vampire games, including fast vanish/reposition movement. The project does not include copied or ripped Dawnwalker code, models, textures, animations, dialogue, music, voice recordings, cinematics, UI assets, or other proprietary content.

The shipped `Nightwalker.dialogue` text is original Nightwalker project content.

## Optional LML content

No Lenny's Mod Loader content pack is included in `1.0.0-rc1`. Any future optional LML pack must be distributed separately with its own dependency and asset notices.
